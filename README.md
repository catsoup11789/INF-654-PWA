# The Void

## Application Name
**The Void**

## Description
The Void is a moody decision-making web app for users who want a quick answer to a question. It lets people ask for guidance, review past answers, and interact with the app through touch, voice, or motion controls.

## PWA Features
This app includes the following Progressive Web App features:

- **Installable app** via `manifest.json` with standalone display settings and app icons
- **Offline support** using a service worker and cached core assets
- **Offline fallback page** when the app is unavailable
- **Persistent local data** for history and user settings through `localStorage`
- **Web Speech API support** for read-aloud answers and voice dictation
- **DeviceMotion support** for shake-to-answer interactions
- **Haptic feedback** for supported devices
- **Responsive UI** that adapts between desktop and mobile layouts
